# Middlewares

Шар зарезервовано для сторонніх бібліотек (RTOS, файлова система, USB-стек). У поточній версії проєкту таких залежностей немає: фільтр руху, CLI і самоперевірка написані у `firmware/App` і тестуються на хості. Якщо з'явиться сторонній компонент, його версію слід зафіксувати у `docs/architecture.md`, а правила залежностей оновити у `tools/check_deps.py`.
