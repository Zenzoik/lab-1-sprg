# Компоненти та інтерфейси

Плата: NUCLEO-C031C6 (STM32C031C6T6, Cortex-M0+, 32 КБ flash, 12 КБ RAM), SYSCLK = HSI48 = 48 МГц.

> Номери сторінок datasheet потрібно звірити з PDF перед здачею — нижче вказано розділи/регістри, за якими їх легко знайти.

## Розводка пінів

| Функція | Пін MCU | Пін Nucleo (Arduino) | Периферія | Компонент |
|---|---|---|---|---|
| UART TX | PA2 | — (ST-Link VCP) | USART2 | Serial monitor |
| UART RX | PA3 | — (ST-Link VCP) | USART2 | Serial monitor |
| I2C SCL | PA9 | D8 | I2C1 | MPU-6050 SCL, логічний аналізатор D0 |
| I2C SDA | PA10 | D2 | I2C1 | MPU-6050 SDA, логічний аналізатор D1 |
| ADC | PA0 | A0 | ADC1 IN0 | Потенціометр SIG |
| PWM 1 | PA6 | D12 | TIM3 CH1 | Серво 1 (pan) |
| PWM 2 | PA7 | D11 | TIM3 CH2 | Серво 2 (tilt) |
| LED | PA5 | D13 | GPIO output | LD4 (на платі) |
| Кнопка | PC13 | — | GPIO input, pull-up | Кнопка на GND |

## MPU-6050 (InvenSense / TDK)

| Параметр | Значення | Джерело |
|---|---|---|
| Datasheet | MPU-6000/MPU-6050 Product Specification (PS-MPU-6000A), Register Map (RM-MPU-6000A) | invensense.tdk.com |
| Інтерфейс | I2C, до 400 кГц; використовуємо 100 кГц | Product Specification, розділ «I2C» |
| Адреса | 0x68 (AD0 = 0) або 0x69 (AD0 = 1) | Product Specification, розділ про I2C-адресу |
| Живлення | VDD 2.375–3.46 В → живимо від 3V3 Nucleo. Модуль GY-521 має власний стабілізатор і допускає 5 В на VCC | Product Specification, електричні характеристики |
| Споживання | близько 3.9 мА (гіроскоп + акселерометр) — допустимо для піна 3V3 | Product Specification, електричні характеристики |
| Піни | VCC, GND, SCL, SDA, AD0 (вибір адреси), INT (переривання), XDA/XCL (допоміжна шина, не використовуємо) | — |
| Ідентифікація | WHO_AM_I (0x75) → 0x68 | Register Map |
| Запуск | PWR_MGMT_1 (0x6B): скинути біт SLEEP (після ввімкнення чіп спить) | Register Map |
| Дані | ACCEL_XOUT_H…ACCEL_ZOUT_L (0x3B–0x40), GYRO_XOUT_H…GYRO_ZOUT_L (0x43–0x48), 16 біт, big-endian | Register Map |
| Діапазони | ACCEL_CONFIG (0x1C), GYRO_CONFIG (0x1B); за замовчуванням ±2 g і ±250 °/с | Register Map |

## Потенціометр (10 кОм)

| Параметр | Значення |
|---|---|
| Інтерфейс | Аналоговий, ADC1 IN0 (PA0), 12 біт (0…4095) |
| Діапазон напруги | 0…3.3 В (крайні виводи на GND і 3V3, середній — на PA0). 5 В подавати не можна: вхід ADC не розрахований на напругу вище VDDA |
| Споживання | 3.3 В / 10 кОм ≈ 0.33 мА |
| Регістри | немає; читання — `HAL_ADC_Start` → `HAL_ADC_PollForConversion` → `HAL_ADC_GetValue` |

## Кнопка

| Параметр | Значення |
|---|---|
| Інтерфейс | GPIO input, PC13, внутрішня підтяжка pull-up |
| Логіка | Натиснуто = 0 (замикає на GND), відпущено = 1 |
| Примітка | Потрібне програмне усунення брязкоту (10–20 мс) |

## Сервопривід SG92R (Tower Pro) ×2

| Параметр | Значення |
|---|---|
| Інтерфейс | PWM, період 20 мс (50 Гц), імпульс ≈ 1000–2000 мкс, 1500 мкс — центр |
| Таймер | TIM3: 48 МГц / (47 + 1) = 1 МГц → 1 такт = 1 мкс; Period = 19999 → 20 мс |
| Живлення | 4.8–6 В → пін 5V. Сигнальний вхід сприймає 3.3 В логіку |
| Споживання | Струм під навантаженням значно перевищує можливості піна 3V3; на реальному залізі два серво краще живити від зовнішнього джерела 5 В зі спільною землею |
| Піни | GND (коричневий), V+ (червоний), PWM (помаранчевий) |

## USART2

115200 бод, 8 біт даних, без парності, 1 стоп-біт (8N1), PA2 — TX, PA3 — RX. На реальній платі це віртуальний COM-порт ST-Link, у Wokwi — `$serialMonitor`.
